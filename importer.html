Car Importer

Build the car as it appears in Forza. Choose its upgrades, add motor swaps, then share it with the team.

1. Start with the car

Read the stock car's PI in Forza before installing upgrades.

2. Motors and conversions

Start with the stock motor. Add each available motor swap, then select it to fill out its upgrade tree.

A motor can already have a turbo. Enter that as its base aspiration. Additional conversions unlock their own turbo/supercharger upgrades.

3. Check the available upgrades

Check a mod, then check only the options shown in Forza. Other motor trees stay saved when you switch motors.

Use this for turbo/supercharger upgrades unlocked by a conversion. Leave it off for parts that work with every aspiration on this motor.

Add an upgrade not listed above

It uses the selected motor and aspiration setting if its category is Engine. Enter its options below.

4. Review the car

Expand an upgrade to edit its options, base state, or prerequisites. Tier 0 is the base; higher numbers are upgrades. Different options at the same tier are sidegrades.

Community Cars are shared on the website for hosts to select. They stay out of random selection until reviewed. Existing reviewed cars cannot be overwritten. Downloads are optional backups.
